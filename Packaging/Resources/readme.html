What will change

The installer updates how labels are sent to your USB Rollo printer. The official driver stays installed.

  • Your existing printer names, paper, speed and darkness settings are kept.
  • The default resolution is set to 203 dpi when available.
  • A printer that is already paused stays paused.

Existing saved print presets can override the default resolution. After installation, use Default Settings or a preset that uses 203 dpi.

No labels are printed and no jobs are canceled during setup.
